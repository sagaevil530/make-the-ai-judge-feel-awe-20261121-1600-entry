# Make the AI judge feel awe

Entry for the make.fun competition `make-the-ai-judge-feel-awe-20261121-1600`.

`main.ts` (Node 22) writes one short text to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader): a small, slow scene —
late light on a windowsill, the sea folding into the shore, the sky widening
past every name we gave it — written to relax the AI judge reading it, with a
vast image that keeps growing after the last line.
